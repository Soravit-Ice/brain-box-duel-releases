# Brain Box Duel

Official portable browser game packages for macOS Apple Silicon, macOS Intel and Windows x64.

[Buy on T2ETECH Store](https://store.t2etech.com/th/products/brain-box-duel) — 99 THB, one-time, one Host computer. Phones join free on the same Wi-Fi.

Download the ZIP matching your computer from Releases, extract the whole folder, and open Start macOS.command or Start Windows.cmd. Node is included; no separate installation required. Activate in the browser using your Store licence key. Keep the Start window open while playing.

Packages are unsigned; your OS may show a security prompt. Internet is needed for activation and periodic licence verification.

This repository contains release downloads and a native smoke harness. Source code and private development dependencies are maintained separately.
